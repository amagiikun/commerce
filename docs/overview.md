# 项目概览

`Smart Commerce Admin` 是一个基于 `Vue 3 + Express + Prisma + MySQL`
的电商运营后台项目，定位为适合写入简历的中后台作品。项目同时覆盖前后端：
前端负责页面、状态和交互，后端负责鉴权、聚合接口、业务列表查询与持久化。

## 目标

- 展示完整中后台从页面到 API 的交付能力
- 保持清晰的前后端接口契约，降低联调成本
- 用演示账号和 seed 数据快速完成本地联调与演示

## 当前能力

- 基于角色的登录鉴权与菜单控制
- 商品、订单、活动等典型后台列表场景
- MySQL 持久化商品编辑结果
- 动态聚合的看板接口

## 适合场景

- 简历项目与面试讲解
- 中后台设计与实现演示
- 从前端 Mock 过渡到真实后端的教学样例
